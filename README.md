## 📖 Descripción

Este proyecto fue desarrollado para ayudar a Super América a tomar decisiones informadas sobre el **reposicionamiento de productos** y **optimización de infraestructura**. El contador del supermercado proporcionó datos reales de ventas de aproximadamente 3 meses, los cuales fueron analizados para identificar patrones de compra, productos de alta rotación y oportunidades de mejora en el layout de la tienda.

## 🚀 Cómo Usar

### Requisitos Previos
- Power BI Desktop (para abrir el dashboard)
- Microsoft Excel (opcional, para ver datos originales)
- Python 3.8+ (si deseas reproducir el análisis)

### Instrucciones

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/josehart280/Super_America.git
   cd Super_America
   ```

2. **Abrir el Dashboard:**
   - Abrir `Dashboard/dashboard.pbix` en Power BI Desktop
   - Explorar las diferentes páginas y filtros

3. **Ver los datos:**
   - Los archivos Excel en `Datos/` contienen la información procesada
